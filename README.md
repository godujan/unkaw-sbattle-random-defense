# 운의전쟁 v1.4 — 모바일 4×4 디펜스

게임: https://godujan.github.io/unkaw-sbattle-random-defense/

## 최신 기능
- 모바일 전용 세로 레이아웃: 상단 웨이브·골드·점수, 중앙 4×4 전장, 하단 5속성 강화/선택 영웅 카드/배속·뽑기·합성
- 같은 속성·등급의 영웅은 **기존 칸에 자동으로 겹치며 ×N** 표시
- 스택 영웅의 수량은 공격력에 합산되고, 동일 등급 3명 합성 시 보유 수량에서 차감됩니다.
- 영웅 판매는 한 번에 1명씩 차감합니다.
- 8등급: 커먼 → 언커먼 → 레어 → 유니크 → 에픽 → 신화 → 태초 → 창조
- 소환 비용 **10원 고정**, 적 처치 +1원, 5웨이브 네임드 +30원, 10웨이브 보스 +60원
- 60초 자동 웨이브, 최대 80웨이브
- 게임 기록/닉네임 복원용 백업 코드, 선택적 Supabase 이메일 링크 로그인

## 배포
GitHub Pages: `.github/workflows/pages.yml` 이 `main` 브랜치 변경 시 정적 사이트를 배포합니다.

## 주의
프로필 백업 코드는 **본인 인증용 계정 코드가 아닙니다**. 서버 인증은 Supabase 설정이 있어야 합니다.
말랑 운빨 디펜스의 모바일 중심 화면 배치를 참고한 독립 게임이며 기존 캐릭터·소스 코드를 복제하지 않았습니다.
