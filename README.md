# 블리치 운빨 디펜스 — 컴팩트 모바일 v1.3

말랑 운빨 디펜스의 모바일 인터페이스 구성(상단 라운드/재화, 중앙 전투, 하단 소환/합성/판매/배속)을 참고하여 **별도로 재구현**한 4×4 방어전입니다.

## GitHub Pages 업로드

1. ZIP 압축을 푼 뒤 내부 파일(index.html, icon.svg, auth-config.js 등)을 저장소 최상위에 올립니다.
2. GitHub 저장소 Settings → Pages → Deploy from a branch → main / root 선택.
3. 모바일 브라우저에서 GitHub Pages URL을 열어 플레이합니다.

## v1.3 변경

- 소환 비용 10원 고정 (혜택을 받아도 변하지 않음)
- 게임 화면은 상단 라운드/시간/재화, 4×4 전장, 하단 **판매 / 배속 / 뽑기 10 / 합성** 중심으로 압축
- 속성 강화·정지·확률표·프로필은 우상단 메뉴로 이동
- 개인 프로필에 **백업 코드 생성 및 복원** 기능. 닉네임, 노멀 클리어 횟수, 최고 웨이브, 승리 횟수 등 전적 포함
- 8단계: 커먼, 언커먼, 레어, 유니크, 에픽, 신화, 태초, 창조
- 선택 영웅 상세창, 속성별 공격력 강화, 60초/웨이브, 80웨이브 유지

## 계정 코드 보안 및 동기화 주의

이 버전의 `BL13-...` 코드는 **로컬 프로필 백업·가져오기** 기능이며 서버에서 인증되는 로그인 토큰이 아닙니다. 이를 복사해 다른 기기에서 프로필을 복원할 수 있지만, 기기 간 실시간 자동 동기화는 하지 않습니다. 코드는 누구나 변조할 수 있으므로 공개 랭킹·거래·신뢰할 수 있는 인증 용도로 사용하지 마세요. 코드가 다른 사람에게 전달되면 기록을 복원할 수 있습니다. 서버 인증 및 안전한 복구 기능은 별도 백엔드 구성이 필요합니다.

본 버전은 이전 버전 이메일 인증 관련 파일을 호환성 목적으로 포함하지만, 주 UI는 코드 기반 백업/가져오기를 우선합니다.

## 배포 상태
GitHub Pages는 `.github/workflows/pages.yml`을 통해 `main` 브랜치 push 시 자동 배포됩니다.
