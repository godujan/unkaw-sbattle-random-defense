# 운의전쟁 v1.5 — 모바일 4×4 개발 버전

## v1.5 변경사항
- **v1.4 공개본 유지:** `v1.5-preview` 브랜치에서 개발 (main 덮어쓰기 금지)
- 캐릭터를 원형 초상화 대신 **고해상도 인간형 카드 초상**으로 표시 (게임 화면에 2× 렌더링 소스 적용)
- 한 칸에 같은 속성/등급/이름 영웅 자동 스택 `×1, ×2, ×3 ...` (UI 자체 상한 없음; 자바스크립트 정수 안전 범위 내)
- **속성별 총 보유 수** 기준 공명: 3명 이상 공격력 강화 **+2레벨**, 5명 이상 **+5레벨**; 두 단계 중 높은 보너스 하나 적용
- 얼음: 1.7초 이동속도 감소 / 물: 받는 피해 +22% 방어 약화 / 불: 최대 30회 화상 중첩 / 번개: 최대 2명 연쇄 / 바람: 매 공격 정확히 2타
- 태초·창조 등급: 상시 반짝임 효과
- 게임 시작 버튼 누를 때 Fullscreen API 요청 (지원하지 않는 모바일 브라우저는 원래 화면으로 유지)
- 8등급 확률표에 캐릭터 아이콘·속성별 확률·합성·판매 정보 표시
- 랭킹 모달: 시즌 / 오늘 / 내 기록. **공개 랭킹 백엔드 미연결 시 가짜 데이터 대신 안내만 표시**
- 프로필: `0000-0000-0000-0000` 형식의 로컬 **플레이어 식별 코드** + 기존 긴 백업 코드 유지. 식별 코드만으로 서버 계정 인증·기기간 자동 복원은 되지 않음.

## GitHub Pages
`v1.5-preview` 브랜치에서 코드 검토 후 운영 `main`에 병합하세요. Pages는 main 브랜치를 배포합니다.

## 인증/랭킹 제약
실제 로그인은 Supabase URL/Publishable key 설정 후 이메일 매직 링크로 수행합니다. 공개 글로벌/시즌 랭킹은 인증, 데이터베이스 및 서버측 기록 검증이 구축돼야 합니다. **이번 버전 랭킹 UI는 실제 미연동 상태를 정직하게 표시**합니다.
